## 🔴 Bulgu Detayı — 14 finding cross-check ile sınıflandırılmış

### KRİTİK (3) — Runtime Doğrulanmış Risk

#### A1 — PostToolUse Bash command leak (events.jsonl'a secret sızar) 🚨

**Sorun konumu:** `hooks/post-tool-use.json:9`
```python
tgt = ti.get("file_path") or ti.get("path") or ti.get("command") or "<no-target>"
```

**Runtime smoke test kanıtı (2026-05-07):**
```
INPUT: {"tool_name": "Bash", "tool_input": {"command": "echo TEST_API_KEY=ghp_<REDACTED-PLACEHOLDER>"}}
OUTPUT (events.jsonl'a yazılırdı):
  audit_target = "Bash:echo TEST_API_KEY=ghp_<REDACTED-PLACEHOLDER>"
```

Bash command **tam olarak** `audit_target` field'ına yazılır. Süleyman bash'te API key, password, token paste ederse → **events.jsonl'a kaydedilir** → events.jsonl workspace repo'da git'te commit edilir → public açıldığında secret leak.

**Fix kapsamı:**
```python
# Bash için command head + redact rest
if tn == "Bash":
    cmd = ti.get("command", "")
    head = cmd.split()[0] if cmd else "<empty>"
    tgt = f"{head} [REDACTED args]"
else:
    tgt = ti.get("file_path") or ti.get("path") or "<no-target>"
```

**Test contract aday:** `tests/hooks/test_post_tool_use_audit_emission.py::test_bash_command_redacted_in_audit_target`

#### A2 — PreToolUse Bash bypass (Excel lock + secret scan ATLANIR) 🚨

**Sorun konumu:** `hooks/pre-tool-use.json:5` matcher
```json
"matcher": "Edit|Write"
```

**Runtime kanıt:** Bash NOT covered. Süleyman:
```bash
python3 -c "import openpyxl; wb=openpyxl.load_workbook('master.xlsx'); ws=wb['cannibalization']; ws['A1']='X'; wb.save('master.xlsx')"
```
yaparsa, **Excel lock check + secret scan TAMAMEN bypass** olur. Excel açıkken iki taraflı yazım → data corruption.

**Fix kapsamı:**
1. Matcher genişlet: `"Edit|Write"` → `"Edit|Write|Bash"`
2. Bash hook'unda command parse: master.xlsx mention varsa lock check yap
```python
# Bash branch: detect master.xlsx in command string
if tn == "Bash":
    cmd = ti.get("command", "")
    # Match "master.xlsx" mention with fuzzy detection
    import re
    match = re.search(r'([\w/.-]+(?:_MASTER|master|-master)\.xlsx)', cmd)
    if match:
        target = pathlib.Path(match.group(1))
        sidecar = target.parent / ("~$" + target.name)
        if sidecar.exists():
            sys.stderr.write(f"BLOCKED: Excel/LibreOffice owner-lock at {sidecar}\n")
            sys.exit(2)
```

**Test contract aday:** `tests/hooks/test_pre_tool_use_excel_lock.py::test_bash_master_xlsx_lock_detected`

#### A3 — PostToolUse audit_action her zaman "accessed" (schema enum yarı kullanım)

**Sorun konumu:** `hooks/post-tool-use.json:9` `audit_action="accessed"` sabit
**Schema:** `events.schema.json` audit_action enum `["created", "modified", "deleted", "accessed", "permission_changed", "config_changed"]`

Şu an:
- Edit → "accessed" (yanlış, "modified" olmalı)
- Write → "accessed" (yanlış, "created" veya "modified")
- Bash → "accessed" (kabul edilebilir default)

drift-check + monitoring-weekly bu trail'den anlam çıkarmaya çalışıyor — semantik null.

**Fix kapsamı:**
```python
# Tool-specific semantic mapping
audit_action = {
    "Edit": "modified",
    "Write": "created" if not pathlib.Path(tgt).exists() else "modified",
    "Bash": "accessed",  # Default; rm/mv command parse aday Tier 3 polish
}.get(tn, "accessed")
```

**Test contract aday:** `tests/hooks/test_post_tool_use_audit_emission.py::test_audit_action_semantic_mapping`
